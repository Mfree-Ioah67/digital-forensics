# Digital Forensics (FRS301)

A comprehensive collection of materials and resources for Digital Forensics investigations and analysis.

## Course Overview

This repository contains educational materials covering the fundamentals and advanced techniques of digital forensic investigations. The content focuses on technical and legal aspects of digital evidence handling, analysis tools, and investigative methodologies.

## Learning Objectives

- Understanding digital forensics principles and applications
- Mobile and GPS forensics techniques
- Digital information storage and retrieval methods
- Forensic environment setup and tool validation
- Digital evidence collection and chain of custody
- Windows artifacts analysis
- Data recovery and hidden data detection
- Legal aspects of digital forensics
- Network forensics and attack investigation
- Social media and communication forensics

## Repository Structure

- **CHFI-Slide/**: Course presentation materials covering 22 modules
- **File-Download/**: Forensic tools and software (FTK Imager)
- **Hands-on Labs/**: Practical exercises and lab materials

## Key Topics Covered

1. Computer Forensics Fundamentals
2. Investigation Process and Procedures
3. Digital Evidence Handling
4. Windows Forensics Analysis
5. Data Acquisition and Recovery
6. Network and Mobile Forensics
7. Steganography and Password Analysis
8. Legal and Expert Witness Procedures

## Tools and Software

### Virtualization Environment
- **Oracle VirtualBox** - Primary virtualization platform for forensic labs

### Forensic Analysis Tools
- **Autopsy** - Digital forensics platform and GUI for The Sleuth Kit
- **FTK Imager** - Disk imaging and evidence acquisition
- **Event Log Explorer** - Windows event log analysis
- **Hashcat** - Advanced password recovery and hash cracking
- **Kali Linux** - Penetration testing and forensic analysis distribution

### Network Analysis
- **Wireshark** - Network protocol analyzer and packet capture
- **Snort** - Network intrusion detection system

### Hash Verification Tools
- **md5sum** - MD5 hash calculation and verification
- **sha1sum** - SHA-1 hash calculation and verification  
- **sha256sum** - SHA-256 hash calculation and verification
